## Concordance and sense decision

- Refreshed allowlist count: **948 hits in 244 storage files**.
- One corpus-wide sense: ‘whole/complete’ (全) + ‘trigger/pivot/dynamic’ (機). Nominal, predicative, verse, rubric, and comment uses share the wording ‘the whole dynamic’; no master-specific meaning was found.
