# 單提 research

- Depth classes retained: explicit contrast, institutional formula, literal instruction with expressed object, and military-object formula. Phrase/move and command uses were checked but not duplicated.
- Family cross-check: 提起 and 單單提起 express the same raising action; 第一句/向上一著/無/正令 supply different objects. The entry does not recategorize the verb as a practice or method.
- Sense audit: one transitive act with multiple objects. Object variation is not polysemy.
- #0g: “raise alone” becomes a productive teaching-seat verb applied to a word, phrase, move, command, matter, or sword.
