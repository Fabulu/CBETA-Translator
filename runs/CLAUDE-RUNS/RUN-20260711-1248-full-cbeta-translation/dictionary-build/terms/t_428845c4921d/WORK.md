## Family and sense audit

- Plain definition: an instant is a very short interval.
- `一念`, `彈指`, `頃刻`, and `萬劫` are comparison or neighboring duration families, not interchangeable Chinese spellings.
- `剎那生滅` (8 / 5) names arising and ceasing at each instant; `剎那三昧` (8 / 3) is a longer named concentration compound. Neither makes the bare time-unit a second referent.
- Sense result: **KEEP one sense.** Duration, subdivision, comparison, sequence, and instant-versus-ages contrast all use the same time-unit. Different events assigned to it are deployments, not different things.
- sense-target-distinguishability: **ONE SENSE.** “An instant,” “a moment,” and “a tiny interval” are translation variants for one unit, not separate targets requiring a split.
- Search aliases: instant / moment / split second / brief instant / fleeting moment. “Split second” is retrieval language for extreme brevity, not an asserted conversion to SI time.
