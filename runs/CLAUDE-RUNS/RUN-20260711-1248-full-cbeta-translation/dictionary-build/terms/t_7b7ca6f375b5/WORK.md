# 罔措 research

- Concordance: 936 hits in 220 allowlisted texts. Definition-formula searches did not yield a direct graph definition.
- Deployment inventory: public-interview aftermath after silence, shout/laughter, a follow-up challenge, and a retrospective case report; ordinary prose/verse uses were reviewed but add no different referent.
- Depth decision: six anchors preserve five independent texts and the distinct silence/action/follow-up/retrospective shapes. Duplicate retellings were excluded.
- Sense test: all witnesses name the same failure to find a response or next move; no noun/person/title collision and no master-private meaning.
- Family check: unlike 茫然 (“blank/dazed”), this phrase regularly reports the externally visible absence of a reply. It is compatible with 問答 and 應機 entries: those name the interview machinery and apt response, while 罔措 reports response failure.
- #0g: the graphs remain ordinary, but the corpus bends them into a stock public-interview stage direction. No mystical significance assigned.
