# 語言三昧 — Lane B 38

feedback-inference-verdict: Command of language is mastery of responsive speech: language able to work freely in public exchange. Xuansha’s deaf-person test asks how such command could meet someone who cannot hear, while Dahui and later writers praise or question its reach.
feedback-observations: Verbal command is not self-certifying eloquence; the three-sick-person case tests whether it can meet the person whom language cannot reach.
feedback-falsification-searches: proper names; headings; substring capture; ordinary containment; opposed appraisals.
feedback-counterexamples: The term can praise literary or preaching power, but the retained Chan cases test that same responsive linguistic command rather than creating a separate grammatical sense.
feedback-scope: corpus-wide across distinct works.
lookup-probes: command of language; mastery of speech; language samadhi; responsive eloquence.
opening-interpretation-verdict: smallest reproducible corpus inference.
sense-target-distinguishability: Praise, deployment, and the deaf-person test concern the same command of language under different appraisals.
