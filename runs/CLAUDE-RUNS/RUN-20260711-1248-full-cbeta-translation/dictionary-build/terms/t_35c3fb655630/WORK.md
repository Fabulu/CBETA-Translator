# Research — 驗人

- Count: 181 hits / 103 allowlisted texts.
- Deployment inventory: explicit maxim tied to speaking; chamber test with a named case; long-term use of a saying as test; compounds 驗人眼/驗人關; public question inviting a response. Each distinct class used in the explanation is anchored.
- Definition formulas: no `X者`; the recurring `驗人端的處，下口便知音` ("at the exact place for testing a person, as soon as he opens his mouth you know his tone") is the closest corpus self-description and is foregrounded.
- Family/split audit: checked 驗, 勘驗, 勘辨, 驗人眼, 驗人關, 室中 and 問答. Compounds preserve the same act and differ only in instrument/faculty, so one sense holds. Kept it narrower than 勘辨: 驗人 explicitly takes a person as object.
- Omission audit: redundant repetitions of the maxim were excluded; the evidence spans case commentary, lamp compilation, chamber biography, and teaching-seat discourse.
