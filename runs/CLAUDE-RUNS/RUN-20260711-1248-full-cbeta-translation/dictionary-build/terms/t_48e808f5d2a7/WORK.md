## Sense decision
ONE corpus-wide sense (SenseKey null). Literal 門 gate + 庭 courtyard = a house's frontage,
hence its distinctive teaching approach. Deployed for setting up a house (立/各立/建立門庭).

**Text-drawn contrast (describe-only gold):** 門庭施設 is repeatedly marked as merely OUTER
apparatus and set against the inner hall 堂奧 and the upward road 向上一路 —
"此猶是…門庭施設(邊事)…須知向上一路尊貴自別" / "此猶是門庭施設…衲僧分中了無交涉". This is a
contrast the corpus itself draws, recorded here without gloss.
