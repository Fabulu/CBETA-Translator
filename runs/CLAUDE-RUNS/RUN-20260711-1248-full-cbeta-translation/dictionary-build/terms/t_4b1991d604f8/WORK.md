# 言下大悟 — “greatly awakened at those words”

## Concordance and sense decision

- Allowlisted count: 542 hits in 160 texts.
- One corpus-wide narrative-formula sense. “At the words” (言下) fixes the event’s position immediately after speech; “greatly awakened” (大悟) names the reported event.
