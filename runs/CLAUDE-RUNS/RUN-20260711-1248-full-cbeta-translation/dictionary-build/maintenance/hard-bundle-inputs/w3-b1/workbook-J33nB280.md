結制，小參。按拄杖，云：「未結制前，一任諸人橫衝直撞，東去西來；既結制後，把斷要津，不通消息。而今正在已結、未結之間，汝等諸人并十方凡聖、草木叢林命如懸絲，俱在山僧手裏，還有出得者麼？」僧問：「祖令初行，續四祖千年遺唱，即今座下誰是知音？」師云：「無眼、耳、鼻、舌、身、意者。」進云：「恁麼則一音演暢，眾德攸聞去也。」師云：「聞底事作麼生？」進云：「今古迥超圓智體，滿筵目擊更無私。」師云：「閑言語。」進云：「和尚把關大煞。」師云：「三十棒且待別時。」問：「向上關捩，千聖不傳，一涉言詮，便落遮畔。如何是那畔底消息？」師云：「你在遮畔多少時也？」進云：「今朝覿面無私。」師云：「猶隔一重山。」僧便喝，師打，云：「還要強作主宰在。」乃云：「覿面全提，向上向下，遮畔那畔，無相無名。恁麼見解，是諸方普請會底，菩提門下許伊擔屎有分。且道菩提有什麼長處便恁麼道？蓋為諸人未達其源，一向在陰界中學得一堆一擔，蘊在八識田中，將古人竭力為人處，不是渾圇吞棗，便邪知謬解、妄用妄談，迷惑無知，害豈有極？山僧遮裏並無些子佛法玄妙，為汝諸人亦不會攢華簇錦、四六文章、語句尖新、逞奇弄巧。汝等若要學遮些，卻請諸方去。山僧者裏只是論實不論虛，今當結制之始，與你們約法三章：第一、不得按牛喫草；第二、不得竿木逢場；第三、不得穩坐平地，透脫三重關，直得胸次中空裸裸地，然後向遮裏看箇話頭，開口也打、不開口也打，不得向意根下卜度、不得向舉起處承當、不得坐在無事甲裏、不得乍寒乍熱，忽朝桶底打穿，管取呵呵大笑。且道笑箇什麼？」喝一喝。
