```text
因事普說。「留得殷勤請得真，龍驤虎驟各生嗔，須知叢社千秋下。應羨忘軀為法人。大眾！天地間有二種法：一曰王法、二曰佛法。復有四種人：知法守法、知法犯法、知法為法、不知法為法，是為四種人。知法守法者，在世間則為君子、為賢人，出世間則為高僧、為德士。知法犯法者，在世間則為小人、為殘賊，王法所必誅，出世間則為裨販、為邪魔，三途所必陷。何謂知法為法？即今天下弘宗演教，據位稱師者，自知無上玅法旨趣，復為法求人以紹續此法，使燈燈不斷者是。何謂不知法為法？即今天下有志衲子，腰包頂笠，撥草瞻風，親明師、求益友，決擇此無上玅法者是。譬如今日之事，西江耆舊遠齎合省護法書幣，冒險乘危，四番請歸翠巖。豈不是為法？本山耆舊鳴鐘擊鼓，羅拜遮留，豈不是為法？留得愈堅，請得益切。一則曰我輩千辛萬苦，重興翠巖，原為和尚；一則曰我家和尚在江右十餘年，化導已久，嗣法有人，今始歸家，坐席未暖，豈可復出？兩家議論不一，未免嗔心忿起，言語參商。大眾！即此一段公案，千古之下可為標格。何故？若為爭勢利、競人我而嗔，則非衲僧家事。今既為法而爭，則嗔者、罵者，請者、留者，與夫堅臥不起者，皆足為叢林盛事。天下出家之徒，儻箇箇肯如此忘軀為法，則佛法日盛，自不至有犯法之事。更舉箇古人公案與諸公商量。昔風穴沼禪師于郢州衙內上堂，云：『祖師心印，狀似鐵牛之機，去即印住、住即印破。祇如不去、不住，印即是？不印即是？還有人道得麼？』時有盧陂長老出問：『學人有鐵牛之機，請師不搭印。』穴曰：『慣釣鯨鯢澄巨浸，卻嗟蛙步𩥇泥沙。』陂佇思，穴喝云：『長老何不進語？』陂擬議，穴便打一拂子，曰：『還記得話頭麼？試舉看。』陂擬開口，穴又打一拂子。牧主曰：『信知佛法與王法一般。』穴曰：『見甚麼道理？』牧主曰：『當斷不斷，反招其亂。』穴便下座。大眾！今日江西緇素請去，黃巖耆舊留住，一眾共知。且如何是去即印住、住即印破底道理？」眾下語不契，丘居士請代，師乃云：「那邊不坐空王殿，爭肯耘田向日輪？」
```
