```text
上堂。舉：「僧問忠國師：『青青翠竹，盡是法身；鬱鬱黃花，無非般若。有人不許，云是邪說；亦有信者，云不思議。不知若為？』國師云：『此是普賢、文殊境界，非諸凡小而能信受，皆與大乘了義經意合。故《華嚴經》云：「佛身充滿於法界，普現一切群生前，隨緣赴感靡不周，而常處此菩提座。」翠竹既不出於法界，豈非法身乎？又《般若經》云：「色無邊故，般若亦無邊。」黃花既不越於色，豈非般若乎？深遠之言，不省者難為措意。』又華嚴座主問大珠和尚云：『禪師何故不許青青翠竹盡是法身，鬱鬱黃花無非般若？』珠云：『法身無象，應翠竹以成形；般若無知，對黃花而顯相。非彼黃花翠竹而有般若法身，故經云：「佛真法身，猶如虛空；應物現形，如水中月。」黃花若是般若，般若即同無情；翠竹若是法身，翠竹還能應用。會麼？』座主云：『不會。』珠云：『若是見性人，道是亦得、道不是亦得，隨用而說，不滯是非；不見性人，說翠竹著翠竹、說黃花著黃花、說法身滯法身、說般若不識般若，所以皆成諍論。』妙喜云：『國師主張青青翠竹盡是法身，主張到底；大珠破除青青翠竹不是法身，直破到底。老漢將一個主張底、一個破底收作一處，更無拈提，不敢動著他一絲毫，要你學者具眼透國師底金剛圈，又吞大珠底栗棘蓬。具眼者辨得出，不具眼者未必不笑。』」師舉起拂子，云：「若道拂子是法身，落他國師圈圚裏；若道拂子不是法身，落他大珠圈圚裏；若道不得道是、不得道不是，又落他妙喜圈圚裡。且道：如何得不落他圈圚聻？」遂擲拂，云：「要出三大老圈圓則易，要出金明圈圚則難。」便下座。
```
