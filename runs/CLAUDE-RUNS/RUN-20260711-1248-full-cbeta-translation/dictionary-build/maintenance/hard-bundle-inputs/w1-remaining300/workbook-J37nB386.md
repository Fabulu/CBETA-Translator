「前日有箇知事進方丈，白云：『各寮行單雖是屢蒙開示，奈何後學初機根器頑鈍，多說和尚佛法深奧，總不省得一些些。望和尚慈悲委曲開示，或有易得明曉底佛法與他們說說。』山僧不覺失笑。噓！屈哉，屈哉！山僧自到者裏來說底話，那一句子是不分明直截底？那一句子是謾昧你諸人底？莫道山僧，乃至從上古今言教，一千七百則爛葛藤、五千四十餘軸破故紙，那一句、那一言不是分明直截底？所以道：寧可說阿羅漢有三毒，不可說如來有二種語。如來實無二種語，祖師又道兩口無一舌。山僧到者裏直是分疏不下，正不知那一句是深、那一句是淺？那一則是難、那一則是易？教山僧如何揀得出來？嗄！有了。記得當初有箇鳥窠和尚，因侍者告假，鳥窠云：『你那裏去？』者云：『諸方學佛法去。』鳥窠云：『若是佛法，我者裏也有些。』者云：『請和尚慈悲。』鳥窠便拈起布毛一吹，侍者當下便悟去。者便是易底了。」師亦拈起布毛吹一吹，云：「還有悟底麼？」眾皆默然，師云：「恁麼總不見有悟底。若是者箇說話不會，更有什麼說話是易底聻？即心即佛是易底，也不出者一吹；非心非佛是易底，也不出者一吹；放下著洗缽盂去是易底，也不出者一吹；天龍豎指、忻州打地是易底，也不出者一吹。至於德山棒、臨濟喝、乾屎橛、麻三斤，古今知識、天下老和尚橫說豎說、千說萬說、塵說剎說、晝夜說、熾然說，無間歇，還出得者一吹麼？既出不得，如今合當悟去，因甚不悟？嗄！莫是古來知識底佛法有靈驗，而今山僧底佛法無靈驗那？嗄！或者山僧底佛法無靈驗也不可知。秖如古人見桃花悟去底聻？難道桃花也是古時底有靈驗，而今底不靈驗了？又有箇聞擊竹聲悟去底聻？難道擊竹聲也是古時底有靈驗，而今底不靈驗了？還有箇聞驢鳴悟去底聻？聞馬叫悟去底聻？聞蝦蟆聲、畫角聲悟去底聻？乃至聞種種聲、見種種色悟去底聻？難道者些驢馬畫角之類多是古來則靈驗，而今都不靈驗了？諸仁！素無此理，仔細參詳看。若是而今底桃花依舊是古來底桃花，擊竹聲也是古來底擊竹聲，與夫驢鳴馬叫、蝦蟆畫角之類都不相異，依舊古來底一般。既是都不相異依舊一般，則適來山僧者一吹也與當時鳥窠底者一吹不相異也。若既不相異，則山僧底用處即是古人底用處，古人底用處即是山僧底用處。既然用處總是一般，古人若有靈驗，則山僧亦有靈驗；山僧若無靈驗，則古人亦無靈驗也。若是者樣看來，你們向來所參底什麼話頭？麻三斤、乾屎橛、狗子無佛性、庭前柏樹子，萬法歸一，一歸何處？父母未生前本來面目，乃至門口也打不開、口也打觸不得、背不得，者一絡索豈不都是古人底？既無靈驗，都不靈驗了也，枉用工夫，有什麼交涉？所以道：本是醍醐上味，遇此等人反成毒藥。信矣！悲夫！灼然！灼然！如今莫道山僧，設使即便喚起從上古錐、德山、臨濟與夫鳥窠船子，運出無量神通、演出諸般玅義，在你者一班瞌睡漢面前又有什麼用處？諸仁！諸仁！你仔細反覆端詳看，畢竟是什麼道理？淆訛又在什麼處？既是佛法本無兩樣，因甚古人便恁麼悟去？如斯快，便如斯瞥脫。你莫道他古人根機利，易得悟；我們根器淺，所以難。我勸你莫作如是話。我問你：你底為生死心，還如古人一般也未？精進決烈，還如古人一般也未？純一無雜，還如古人一般也未？堅心死誓，還如古人一般也未？捍勞忍苦，還如古人一般也未？痛自鞭策，還如古人一般也未？既然不曾如是一番，便要如古人一般樣悟去，也須直待驢年。諸仁！端知此箇事，莫尋他覓，須是自尋門路始得，全不在他語言上。你如今胸次中凡有隔礙透不過處，便是你底生死根本、便是你底真善知識，便當時時請問他、時時與他挨拶，如生冤家一般，一些也不要放過他，久久純熟，有些相應，逢時遇緣，觸著磕著，便悟去也不可知。若是秖教山僧與你說、與你道，莫道賺誤你去，山僧也要留取口喫飯。秖如你更教山僧說箇什麼？道箇什麼？若說禪、說道、說玄、說玅，者箇是造地獄業；若是教山僧警策你一番，究竟你一上者箇自有溈山警策文、怡山發願文、大彌陀、小彌陀種種文，你難道朝暮不曾念那詞句？極是宛轉義理，又極悲切，教山僧說也說不出、做也做不來。嗄！莫是難道和尚自己豈無幾句說話開發他們？只管引古引今，推托作麼？你若恁麼說話，一發錯過山僧不少矣。你若要知山僧底委曲開示處麼？打版時共你齋堂裏喫飯，內逼起來與你一般樣後架上屙屎，閒時在繩床上打兩箇瞌睡，夜來伸長了兩腳一𭔏，者箇便是山僧底真實相為處、極新鮮底言句、極明白底佛法。若是開口掉舌、動手動腳，施底玅用、說底佛法，盡是從上老凍儂棄下底涕唾、拋落底草鞋，豈可只管將來穢污你們底心田？」拱手，云：「不要久立，喫茶去！喫茶去！」

披讀來翰過譽，種種重言不當喫。承問：末後一句急切要緊，正搔著山僧癢處。山僧入楚以來雖曰未久，凡見究心此事者，無論在家、出家，略認得些門頭影子邊事，便以為極則，不思進步究竟到安樂無疑之地，佛所云可憐憫者，正此輩耳。而居士特於此要見箇到底，豈非夙承願力而來者乎？雖然，若論末後一句，未舉最初一句以前，已是兩手分付了也，而居士又在山僧者裏撈天摸地。何也？蓋只為居士薦得最初一句，未免史有末後一句，始到牢關之事耳。而今若要山僧說，則截卻山僧舌；若道山僧不說，則啞卻山僧口。居士向者裏還分疏得下麼？分疏看。若分疏不下，直須仔細分疏；忽然分疏不及，啐地折、嚗地斷，則非末後一句和者從前所得一時俱喪卻也，方信道從前被眼瞞也。所以古人道：一見則一切見，一了則一切了。直下如紅爐上飛點雪相似，金剛王寶劍上還吹得一些毛麼？到者裏若有纖毫未盡，即是過重丘山。須知！須知！故云：懸崖撒手，自肯承當；絕後再甦，欺君不得。總無他說，只要當人啐地折、嚗地斷耳。果若啐地折、嚗地斷，豈有未盡之理？高峰墮枕時，便是者箇消息也；百丈耳聾三日，亦不出者箇消息也。至於巖頭道：「大小德山未會末後句在。」又道：「悔不曾向伊道末後句。若向伊道末後句，天下人不奈雪老何。」者等葛藤，一一自知落處，不著問人耳。那時神鼎有三十棒要與居士喫，方知道如蒿枝拂相似。若此，豈特不可與近時流輩得少為足者同日而語，便與從上古人把臂共行矣。不特居士慶快生平，真林下勝事也。勉力。
