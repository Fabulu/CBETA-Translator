```text
向化侯府至，上堂。問：「『天命之謂性』，如何是性？」師云：「這一問從甚處來？」進云：「『率性之謂道』，如何是道？」師云：「只須向腳跟下薦取。」進云：「『修道之謂教』，如何是教？」師云：「莫將黃葉當作金錢。」進云：「不睹不聞處，請師道一句？」師云：「不道不道！」進云：「因甚不道？」師云：「道即不辭，恐落睹聞邊去。」進云：「莫見莫顯又作麼生？」師豎拂子云：「還見這個麼？」進云：「這個且置，侯府大檀來也，和尚如何接待？」師喝一喝。進云：「上上提持即不無，還期曲垂方便。」師云：「若論方便，已是方便了也，更待山僧舉段機緣。昔日明良將軍與六祖同參，六祖得法之後三更夜遯，明趕至大庾嶺。祖見明來，以衣缽置石上，潛身樹間。明至，取衣缽不動，白云：『行者！某非為衣缽而來，乃為佛法而來。』祖云：『衣以表信，豈可力爭耶？既為佛法而來，不思善、不思惡。正恁麼時，那個是明上座本來面目？』明於言下豁然大悟。今日爵臺若為衣缽而來，爵臺本分具足；若為佛法而來，不須山僧重舉。畢竟如何以酬來意？」畫○相云：「荊山有玉君須剖，莫負殷勤抱璞人。」一僧出云：「恁麼道是甚麼心行？」師云：「路逢劍客須呈劍，不是詩人不獻詩。」進云：「何似深藏一片舌，莫教辜負兩莖眉？」師云：「低聲低聲！」問：「在昔功甫入山，白雲道個枕上頌子；即今侯府入山，和尚道個嶺頭大意。一前一後是別是同？」師云：「囉囉哩！哩哩囉！」問：「三聖因甚逢人即出，出則不為人？」師云：「只為婆心重，翻同陌路人。」進云：「興化因甚逢人即不出，出則便為人？」師云：「誰知鐵石心，傾作和腸淚？」進云：「今日底事，和尚是出是不出？」師云：「不妨疑著！」進云：「道是為人不為人？」師云：「謾得過阿誰？」問：「長者布金、譚公捨宅，條例如何？」師云：「朝三暮四、朝四暮三。」進云：「不二門著腳即不問，如何是向上路恰好抽身？」師云：「闍黎禮拜了退。」問：「但有言說，都無實義，哆哆和和作甚麼？」師云：「官不容鍼，私通車馬。」進云：「恁麼則輸藥山一籌也。」師云：「蒼天蒼天！」問：「古人為甚張弓架箭？」師云：「一朝權到手，看取令來行。」僧拂袖歸眾，師云：「金鱗燒尾龍門去，收取絲綸別下鉤。」
```
