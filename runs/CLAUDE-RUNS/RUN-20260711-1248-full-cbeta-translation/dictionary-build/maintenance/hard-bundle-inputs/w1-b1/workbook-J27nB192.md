普說。「付法一事，付無所付，於無所付中，接引人人歸正路耳。況此事人人本具，個個不無，在善知識淘汰成就，使大者大成，小者小就。既將佛祖慧命委付，共人自然拳拳服膺，守持勿失，久則道力自充，不覺為出世人矣。山僧既蒙寶壽雨師翁，將象田一枝兩手分付，我不忍斷，故接之。若據本懷，舉世無可我意者。若一味單提格外一著子，令一切人攀攬不著，雖使宗風振於當世，後絕無人，得不辜負先人一片苦心乎？況世亂紛紛，光景不長，危如壘卵，恐一不測，將象田一脈斷卻，得不愧於心乎？丙戌，余主越城天華寺，只得放倒頭來，付囑幾人，正使宗風不致寂寥，後學還有依棲，或天下善知識，乃至一省一府、一縣一山，成就他為人，啟迪後昆，縱是佛來與祖來，一一收歸法海裡，益之也廣，利之也深。如博山亦是大善知識，開堂二十餘年，未曾付囑一人，使江西法道寂寥，會下縱有英靈之士，不過為粥飯主人耳。天奇付三百七十人，唯無聞聰一枝，天童接起，宗風大振海內。洞山亦付四十餘人，唯雲居膺一枝，雲門湛然祖翁接起，兒孫遍滿天下。若非上人高明遠見，焉有今日事？出世弘道，與獨覺自了，實天地懸殊，諸人胡不看大人之用心乎？若守定一隅，淺見薄識，名小家子，祖庭傾頹，無人恢復，衲子挑包，無有投奔。故大聖興慈建叢林、立法則興教化者，正為此也。子問付法之益，故將本意酬之。千個參學者不如一省發者，千個省發者不如一付法者，千個付法者不如一出世者。以此較之，付法出世者必有長，不付法而流落者必有短。長短岐分，子當自辨。珍重！」
