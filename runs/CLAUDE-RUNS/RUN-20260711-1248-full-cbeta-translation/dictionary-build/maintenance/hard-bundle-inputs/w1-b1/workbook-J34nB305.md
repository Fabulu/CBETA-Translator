浹歲，遂至成帙。嘗示眾，驀拈拄杖，云：「內絕見聞覺知，外冥山河大地，萬仞壁立處，千波競起；一點不來時，諸法橫生。」卓一下，云：「要用直須用，眼目莫定動。」又云：「道無心合人，人無心合道，欲識箇中意，一老一不老。三從六義中，老者燒火掃地，小者喫粥喫飯，不老不小底叫他作甚麼？」良久，云：「近來米價甚貴，無處著他。」便起身。又云：「我作佛事，淵乎！玅哉！纔方洗缽，瞌睡又來，空山無人，水流花開，那知住處，喚作天台。」又云：「未明心地印，難透祖師關；欲透祖師關，須明心地印。」拈起拄杖，云：「這箇是心地印。」畫一畫，云：「這箇是祖師關。已過關者，掉臂徑去；未過關者，且借印看。」良久，喝一喝，云：「莫怪適來頻勘驗，自從別後見君希。」又云：「長廊下與你說，後架頭與你說，菜不擇一莖，柴不搬一束。而今法堂上若再與你說，國清他時後日喫草去。」又僧纔出，師便喝，僧擬議，師直喝出。良久，乃云：「問者固好，荅者更奇，肯從林下昇天去，也勝時人著錦衣。」又云：「國清今日與諸人一時道卻。」良久，云：「灸瘡瘢上不可更著艾爝。」師文人，既明綱要，輒能以向上一途為人釋縛，如諸法語，固非學士家聰辨可緣，又豈一代時教所能管攝？至其接納故人也，則又勤勤切切，雖黃髮一披至誠，最以大道無所貰。嘗示從兄欽仲二尹，云：「此事須向石火電光中瞥地，不可如遊蜂入窗鑽他故紙。若果二六時中不依倚一物，自然舉足動步，著衣喫飯，全身裏許。苟徒向外馳求，迷頭認影，縱見得箇昭昭靈靈底，正是生死岸頭事。」又云：「德山棒、臨濟喝是甚熱大？人人腳跟下一段光明炤天炤地，莫被他鈍置好。」又示詹確菴明府，云：「確菴從萬壑千峰橫身巨澤，山埜從平田淺草進步懸崖，阮籍途窮之慟、王維雲起之吟，或歌或哭，誰是誰非？辨得即山是山、水是水，銀碗裏盛雪；辨不得山不是山、水不是水，墨汁裏洗炭。阿呵呵！噫嘻嘻！摘遍楊花舞雪衣。」又示周闇昭侍御云：「逝水東流不返，落紅滿地無收，雖入高人圖繪點染成文，轉見不堪耳。唯安心向上，銷歸本地風光，即刀山火鑊等於禪天，大冶精金終無變色。」又示安大巳居士云：「此一段事大非草草，須看得十分急切，于急切不過處忽然打失鼻孔，直下虛空粉碎、魔佛齊捐，自然不假三寸辯若懸河，不拈尺銕蕩平天下，所謂截斷葛藤自有生機一路。若將古人言句視為玄玅，放在皮袋裏數他珍寶，於己何益？」又云：「人人盡有生緣，非生緣能累人，人自為生緣累耳。若厭而求離，其疾益甚。昔有僧問老宿：『世界恁麼熱，未審向甚處迴避？』宿曰：『向鑊湯爐炭裏迴避。』曰：『鑊湯爐炭作麼生迴避？』宿曰：『眾苦不能到。』玅喜謂：『圓悟烊銅熱鐵，是此老家嘗茶飯。』此箇千金秘方，懸之肘後不輕授人，今日為君舉似，且作死馬醫，但不得執方成病，使無上醍醐翻成毒藥。」又示陳孝蔣居士云：「山頭老漢一片婆心，語默動靜無隱乎爾，若著意覷捕，未免向外馳求。求心不息，一紙萬山，缽裏飯、桶裏水，盡是三昧，信口嚼著，說甚一生飽不饑？」又示包朗威孝廉云：「居士具大信力，且又虛懷，不必論他遲速遠近，一有到家消息，便知泣下岐途、悲生逆旅，皆是識情顛倒。從無始來，凡所遊歷城郭、樓臺、山川、林木、人民、車馬，一切可哀、可喜、可驚、可愕之狀，總只屋裏販揚州，並不曾寄宿鄰家廡下。」如上開導，讀者驚歎，如忤逆聞雷，不覺心膽墮地。及拈提古今，據款結案，則又不在雪竇、雲菴之下。嘗舉玄沙拈荔枝示眾云：「這箇得恁麼紅，這箇得恁麼赤，諸人作麼生會？若道一色，猶是儱侗；若道眾色，又落斷嘗。畢竟作麼生？」一僧出云：「不可不識荔枝。」沙自代云：「只是荔枝。」師云：「大小玄沙喫荔枝也費鹽費醬。」又舉：「趙州問大慈：『般若以何為體？』慈云：『般若以何為體？』州大笑而出。明掃地次，慈問：『般若以何為體？』州置帚，拊掌大笑。」師：「大慈騎賊馬殺賊，昨日那邊落節？趙州潔淨地上塵，今朝甚處拔本？國清當日若見，奪苕帚便打，直教這老漢哭了笑不得。」又舉：「南泉因兩堂大眾爭貓，泉提起云：『道得即不斬。』眾無語，泉遂斬卻。至晚，趙州，泉舉前話，州以草鞋戴頭上便出，泉云：『子若在，救貓兒。』」師云：「王老師三十年只殺得箇貓兒，將謂獨行獨市，被趙州輕輕把隻破草鞋便開箇潑天舖子斷上風，直得盡大地人有文大光錢買了喫底、沒著底。國清今日與大眾箇方便。」唾一唾，便下座。如斯演唱，苟不具通方眼目，豈能搆其腋下毛乎？師古道：「物身為眾作則，拳拳誨勵，必欲返虛澆還之大雅，有識咸慶。」以為法門狂砥，端在於斯。無何山罹羅，師匍匐奔赴。辛卯冬，同舟次平川，風大作，天日晝暝，牽舟者盡力前，舟覆，師與山並蹋船屋不至墮，尚能共語。救者從船底上至，師請山先出，山語師先，師甫出，救者亟相接，舟忽欹，船底上人幾胥溺，而師失所在矣。少旋，山出，捄者徐徐引手，乃得全，時十二月二十一日也。哲午，得師水中，則亭亭立，左手為金剛拳，右手掭數珠，含笑如平時，衣與履一無遺脫。眾摩其兩股曰：「請和尚收足入龕。」須臾調耎，頓結雙趺，緇白少長咸詫頂禮。移時纔入龕，而其宗人率師伯子漪來，必欲奉歸，以儒禮殮且葬。眾謂山勿聽，山曰：「先聖捨頭目髓腦成就人，如毘富羅山不生疲厭。曹溪有盜詭麻衣取六祖首歸供，門人皆不問，今其子取其親，何愛此委蛻，不以滿吾儕檀度，成彼孝思乎？」然山語甫畢，先所謂含笑如平時者忽色變，師意可知矣。時山弘法事在官未果，師家人夜以香油鐙作供，數挑必燼，雖易炷如初，如是者輩春秋始。壬辰七月二十五日，忽竟夜明，其家搖首語，莫決所自己，詢之，則山昭雪脫事外。是夜過吳江，方維舟城下，師寂光炯炯交相攝，其家不知也。師有法語卷行世。越五年酉三月朔，其家奉師全身葬於鄧尉山紫嶺，山謂衣往拜墓格於制，而師一代宗工不可無所表顯，取師衣缽同日厝靈嵒山右之佛日嵒，采石為塔之。既落成，山中兄弟同聲語志曰：「國清鄉薦本出入門下，今又同一師學，知之深無逾公者，銘其塔非不可。」志無所得辭，乃拜手而為之銘曰：
