宗云：『若不一番寒徹骨，爭得梅花撲鼻香？』時我憤極，不覺望古師撞上，云：『是甚麼？』師以兩手一掀，翻倒在地，頓覺胸中如剜出心肝，五藏身如在虛空中，又如入水晶簾內相似，所有機緣，後皆忘卻，欲覓一念，了不可得，歡喜之極。古師云：『待你快活快活，再向你道。』及歸，讀古人機緣，有明得明不得者，以問古師，師云：『猶如火發，未至燎天，物像尚在。古人云：「得坐披衣，向後自見。」又云：「末後一著，始到牢關。」』乃復起疑情，志在透徹，室中作聯云：『長為粥飯僧，不復學識；做個癡獃漢，必要明心。』吼崖和尚從山中來，見云：『長為粥飯僧，做個癡獃漢足矣，更要明個甚麼？』及古師圓寂，感其孤高相為，受益良多，冷坐十年，而從上淆訛公案漸得清楚。辛亥春，偶遊普明，問：『和尚是誰？』知客云：『費老和尚門人，從徑山來底。』因隨喜芝根室，見和尚頂相魁巍，肅然敬仰，便有親近之意。知客云：『和尚分衛海鹽回來，即啟萬佛懺期。』先我夢見空馬五六十疋，因騎上一疋，餘皆伏地，視之皆象也，騎向東南而醒，遂有固往普明之志。不數日，知客請我禮懺，便至普明安書記，因與和尚相契，所有問酬機語皆不記錄，蓋我素不喜弄機逞利者。是年，結制安西堂。壬子元旦，領眾入方丈，和尚便以衣拂源流付我，時不肯受，和尚云：『年初一要發利市，不得推阻。』我云：『某甲不要做賣買底。』便出，和尚命侍者送至寮中。時天放、石堂二見，極力相勸，勉強拜受。乙卯戒期後，還歸清隱別室。丙辰秋，月映兄到精嚴，謂云：『老和尚有疾，弟住漏澤，不能朝夕侍奉，必要兄去，大眾方安。』便坐待束裝，即於七月二十七日到寺，和尚大喜，即送首座寮。至八月十八日，和尚自領眾托缽而歸，大喜，至中夜說偈坐化，眾推我料理。自此喫盡苦辛，畫虎不成，今日追思，深為敗缺，大眾珍重！」鐵樹同眾禮謝而退。
