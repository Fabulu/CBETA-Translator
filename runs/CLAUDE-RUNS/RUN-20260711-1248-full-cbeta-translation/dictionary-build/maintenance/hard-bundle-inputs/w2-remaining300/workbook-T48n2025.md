稟辭師長。慕有道尊宿處。依棲求掛搭古規首到客司相看。次往堂司掛搭。送單位經案定。然後到侍司通覆。詣方丈禮拜。今時遊方掛搭初到旦過。推熟於叢林能事者一人為參頭。領眾至客司具威儀。列門首右。白云知客即接入。詞云答云揖坐燒香喫茶略詢來歷。即起謝茶歸旦過。知客尋往回禮。參頭接入。普同問訊。知客詞云答云參頭自送出門。若欲禮拜住持。則放參後詣侍司相看如前禮。起身稟云侍者揖再坐。詳詢來由。或鄉人法眷辦事分明。侍者云即上方丈咨覆。如允次早鍾鳴。侍者令客頭報相看。如未暇。侍者挑燈詣安下處報禮。善言安慰。相看之禮粥罷。參頭領眾。詣寢堂候住持出。侍者接入。參頭進前云轉身左手插香。退身同眾。初展云再展云觸禮三拜。如入室弟子法眷則云別插香行禮就座。侍者燒香喫茶。住持問鄉里名諱及夏在何處。各須實答。不可多語。起身爐前謝云住持送出。參頭云隨至侍司致謝云歸旦過外下手排立。候住持回。禮同問訊接入。詞云住持云眾送出。參頭轉上手接侍者入。同眾問訊云侍者云今遊方者多不入旦過。到處輒尋鄉曲頭首寮舍安泊。古禮漸至無聞。住持遇名勝相看。就送客位回禮。上座相看。就法堂下間。迎伺住持回禮。免煩降重。而五山大方則不回禮。半齋請點心。當晚特為湯披衣赴。住持接入。爐前通寒溫。就坐侍者燒香揖湯。湯罷起就爐前謝湯。須兩展三禮抽衣就坐藥石。如住持不暇。請頭首代相陪。時當自起燒香。住持自伴湯乃盡禮也。次日粥罷請茶。參頭領眾。排立寢堂前。候住持至。即趨前問訊云入座侍者燒香喫茶。起至爐前兩展三禮謝茶。初展云再展云退身觸禮三拜。住持送出兩三步。如求掛搭。參頭領眾回身。進住持前。稟云稟訖不伺允否。即普觸禮一拜云。當先掛搭參頭。其餘不拘早晚。不擇處所。各知進退。伺候住持求住。方丈近事人母得呵禁。如允仍觸禮一拜。就求帖子。到侍司附名云侍者次第發榜頭下堂司維那令行者請新到。喫茶畢出。度牒上床歷候送歸堂。或有故出入。須守堂儀。半月方可請假。古云。請假遊山者常將半月期。過期重掛搭。依舊守堂儀。如迫師長父母疾病喪死者。不在此限。
