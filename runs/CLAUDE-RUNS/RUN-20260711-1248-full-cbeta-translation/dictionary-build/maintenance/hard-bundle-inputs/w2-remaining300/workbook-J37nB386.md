七十一員善知識，末後到首山會下，問：『百丈捲席，意旨如何？』而今禪和家，纔挾箇袱子出來，社火中便謂：者箇因緣，是單頭公案，有甚淆訛？所要透底，是要緊大禪頭，如女子出定，百丈野狐，德山托缽，殃崛產難，莊上喫油餈，牛過窗櫺話。者一落索，謂之末後牢關，用出心機意識，卜度得去，說得相似，以為參學事畢，安肯虛心與麼請問？殊不知未曾直下到啐地折、嚗地斷，便是即心是佛，也有些子淆訛。若但與麼卜度得底，正是依他作解，障自悟門，古人決不如是。前所云：『只為道眼未開，聖心未通，不肯強作主宰，但有纖毫疑滯，到處火急決擇。』如今法座上老師，見他問與麼因緣，定是不將在意，不是喝，便是棒，趁俊快，擊石火，閃電光，蓋覆將去，有甚巴鼻？你看他首山和尚，真是臨濟正傳，卻不用者些惡臭氣，但緩緩地向他道：『龍袖拂開全體現。』直下十日並照，何等光明？到者裏真是師資合處，啐啄同時，觸著者些關捩。汾陽又狼忙問道：『師意如何？』首山更向金不博金處道一句云：『象王行處絕狐蹤。』此時汾陽忽地桶底脫落，如啞子得夢，說似人不得，只說道：『萬古碧潭空界月，再三撈摝始應知。』者般痛快處，豈似你一句來一句去，用些閒文野彩計較卜度得來底？此所謂臨濟道出常情，便是者箇道理。你若者裏不穩當，直饒你說得磨稜合縫、盛水不漏，總是閻羅王手中換鐵棒喫底張本果。若是箇上根利智，不假他力，古人教你坐地搆去、立地搆去，不待呵氣便搆去。因甚不搆去？若與麼搆得去，豈不省卻人多少心力？安用許多忉怛？設若沒者樣俊快底根性，索性剷地，不會底人倒好受人整頓，還打發得撇脫。不見當初俱胝道者結茅住菴，他那裏知得什麼麻三斤、乾矢橛、狗子無佛性、庭前柏樹子？只是胸次中無一箇元字腳，忽地撞著箇惡冤家，一拶直得四稜塌地。你道如何是惡冤家？看他從上風彩，豈不慚惶無地？而今禪客相逢，到處人情世諦，者箇冤家卻是箇五漏身軀。臨晚到俱胝菴中，俱胝見他不下笠子，便道：『何不卸下笠子？』如今名色禪和便打箇問訊，卸下笠子只圖穩便，喚作禪和得麼？你看者箇尼僧雖是五漏之軀，卻是銕橛相似，便與俱胝當頭一拶道：『道得卸下笠子。』倒把箇男子漢看一看，看有氣息無氣息？俱胝本不知東斗，卻是實頭人難得。又道：『天色漸晚，何不且住？』又被他第二杓惡水一潑道：『道得即住。』俱胝口似扁擔，尼僧竟自去了。俱胝不覺觸發狂心，欲燒菴行腳，忽逢天龍豎起一指，當下狂心便歇。所以道：『狂心若歇，歇即菩提。』便是者箇道理。此不是剷地不會底，倒好整理，所以最忌雜毒入心。然古人凡到所在，見箇村院主也須問過。又道：『若遇艸裏有箇漢，便與當頭一拶。看他知氣息，布袋盛米供養他。』是以佛法興盛，良有以也。如今佛法下衰，到處不肯博問先知，一味顢頇過日，見說道：『諸佛法印，匪從人得。』不打在無事甲裏，便是橫生己見、強作主宰、胡說亂道，總是今日老鬍絕望。你看二祖大師為法忘軀，他三乘五教豈不會得？只是者些疑情未破，不到情枯意竭、知見頓忘、能所併絕，萬機寢、萬緣削，爭肯立雪齊腰、捐身斷臂？道：『我心未安，乞師安心。』他又豈不聞：『諸佛法印，匪從人得。』因甚麼如此火急？所以黃檗和尚道：『大事本來如是。若不究到無心處，自見自肯，即埋沒人也。』你看者老臊鬍尋常說箇直指到者裏，果然手段各別，便就向伊身上割一塊子與伊道：『將心來，與汝安。』此時斷臂老子實究到無心處，口供是實，便道：『內外覓心了不可得。』豈不是自見自肯？那老臊鬍便將無文印子一印印定道：『與汝安心竟。』直得無絲毫透漏，豈不是皆因激發中來？你索性要做箇沒意智漢，三十年、二十年口堆白醭，也沒人喚作你是箇啞漢，卻又做不來、卻又不甘心。既不甘心又做不來，便心裏想道：『我在叢林裏三二十年，不是箇老參麼？某老知識親近過、某職事又做過，而今頭白齒黃，將何立在人前做模做樣？』火急向冊子上卜度得一句半句，又不知語言之次序、說話之反正，一般也要向人前放出者般屎臭氣熏人，反不如三家村裏無事漢卻無者些顛倒。你看古人決不恁麼。古來有箇香嚴道者，他在百丈會裏一問十答如瓶溈水，豈似你者般艸包飯袋、寒酸不上眼底垃圾？一日，沒興撞到溈山水牯牛隊裏去，溈山是箇老賊頭，便喚一聲：『師弟！你在百丈會下一問十答是否？』者孟八郎便道：『不敢。』著賊了也。溈山道：『此是汝聰明靈利、意解識想、生死根本。父母未生，試道一句看。』千鈞之弩，果然不為鼷鼠而發機。香嚴被問，直得茫然歸寮，將平日看過底文字從頭要尋一句酬對，竟不可得，乃自歎云：『畫餅不可克饑。』一款招成。香嚴被此一拶，若不是死盡無始劫來底偷心，爭肯恁麼道？所以道：死盡偷心，方堪學道。香嚴到者箇時節，始有參學趣向分了，畢竟真不掩偽、曲不藏直。古人是箇學道底人，如今底人莫說一問能十答，纔到百丈會下住過幾日，或當過職事走到溈山來，便要搖搖擺擺，向方丈裏認同參攀弟兄，做出許多空腹高心、不知慚愧底樣子出來。設若與伊當頭一拶，不是喝一喝、豎一指、裝體面架將去，便道：『我來不是親近你佛法。』孰肯知非？如香嚴老子恁麼道畫餅不可克饑，者箇真是古今師法好樣子。世衰道降，一日不如一日，看到古人好不慚惶殺人也。當時香嚴屢乞溈山說破，溈山道：『我若說似汝，已後罵我在。我說底、是我底，總不干汝事。』真是箇一千五百人善知識，畢竟不同。如今據曲彔木床底更是不堪，若見他肯與麼低頭，便將不中心行出來，甜唇美舌，多方籠籠絡絡，如何使得？他有真正眼開底時節，者般宗師拽下床來，椎殺他千箇萬箇，有什麼罪過？所以天童門下一任路絕人荒，終不作者般不材不淨底事。黃金自有黃金價，何事和沙賣與人？香嚴知是從前錯路，遂將平昔所有底文字燒卻，道：『此生不學佛法了也，且作箇長行粥飯僧，免役心神。』豈不是以有所得心學無所得法，如何學得來？然則香嚴此時卻也平帖帖地了，乃泣辭溈山，溈山更不留，可謂白玉琢成西子骨，黃金鑄就伍員心，不妨千古師資、風雲際會盡在此處。當時者兩箇老古錐，若非等是純鋼打就底脊項，莫道香嚴後來聞擊竹聲悟道，便是聞無限微玅梵音聲、迦陵頻伽聲，也則是箇隨聲逐色底人，安有『一擊忘所知，更不假修持』之慶快平生也？此六祖所謂『若能一念自知非，自己靈光嘗顯現』，便是者箇道理。所以古人寧使一生不悟，不肯半青半黃，依俙相似，得少為足。然古來亦有一箇樣子，喚作南扁頭。者箇扁頭道人，胸羅三藏、學貫五車，其實有些子風彩，只是打頭不遇得箇咬豬狗底手腳，幾乎一生錯過。虧殺他結得箇好道友，喚作雲峰悅。一日，同遊西山，知其不實，悅歎云：『南有道之器也，惜其未遇本分鉗鎚耳。』也是為他閒事長無明。然如今人結道友，人情意況或有之，求其如此相為者，直是萬中無一。夜臥，話及雲門法道，悅云：『澄公雖是雲門之後，法道異矣。』鉤頭著餌。南詰其所以異，一釣便上，悅云：『再加線索。』雲門如九轉丹砂點銕成金，澄公藥汞銀徒可玩，入煆則流去，若藥不瞑眩，其疾不瘳。南怒，以枕投之，猶更𨁝跳。悅明日謝過，不是好心。又云：『一不做，二不休。』雲門氣宇如王，甘死語下乎？澄公有法授人，死語也，死語其能活人乎？雖是死蛇，解弄也活。即背去，有甚交涉？如今底道友家說話不投，便發惡背去；分利不均，便發惡背去；爭人爭我，便發惡背去。求其如此佛法激勵背去者，更是萬中無一。更有一般底在社火中鉤群結隊，互相欺誑，或於老師前說一句好話，便喚作徹骨相為，此正是便辟之友。求其直諒如雲峰之為道友者，其可得哉？那時南扁頭被他打著，心中事便把不住，挽之云：『若如是，則誰可汝意？』果然藥汞銀悅。使見石霜，為人須為徹。南心裏想道：『悅師翠嚴，使我見石霜，於他何干？』此老者一疑，正是命根不斷處。即造石霜。中途聞慈明少叢林，不願見，遂登衡嶽。時來風送滕王閣，乃謁福嚴賢。賢卒，郡守以慈明補之。冤有頭，債有主。既至，目其貶剝諸方，件件數為邪解。南為之氣索，運退雷轟索靖碑。遂造其室，天網恢恢。明云：『書記領徒遊方，借使有疑，可坐而商略。』看者老漢面如夾竹桃華，心裏參天荊棘，者箇甜唇美舌卻用得好。『那扁頭道人畢竟是箇學道底人。』到者裏不敢欺心。哀懇愈切。明云：『公學雲門禪，必善其旨。如云：「放洞山三頓棒。」是有喫棒分？無喫棒分？』如此發藥下刃，豈是你如今捏死蛇底老凍儂？不審機扣相當不相當，一味硬將死法，則魔魅人家男女。他見道穩實底人，自然有一段生機別路，活潑潑地煆煉人，使得他無地藏竄，手腳畢露。道：『有喫棒分。』果然入煆不得。那時慈明捋下面皮來也，不是前番底甜唇美舌了，面上便露幾分惡顏色出來道：『若然，從朝至暮，鵲噪鴉鳴，皆應喫棒。』端著坐，受其炷香作禮。所以道：殺人刀，活人劍，上古之規模，今時之樞要。明又問道：『越州云：「臺山婆子，我為汝勘破了也。」且道那裏是他勘破處？』驢事未了，馬事又到。扁頭直得通身汗下，口似磉盤。殊不知勘破婆子處，便是放洞山棒處。者裏不省得，那裏如何知得？次日相見，慈明詬罵不已，南云：『罵豈慈悲法施耶？』明云：『你作罵會那？』咄！作什麼會？『直饒不作罵會，還夢見麼？』南於言下大悟。早知燈是火，飯熟幾多時？遂作箇頌云：『傑出叢林老趙州』，不勞贊歎。『老婆勘破沒來出』，總使有來由，有甚干涉？『而今四海清如鏡』，平地上死人無數。『行人莫與路為仇』，依舊參天荊棘。你看他恁麼吐露，豈不是胸襟流出，蓋天蓋地？如今人尋常開大口說，驅耕夫之牛，奪饑人之食，及至臨機，全無巴鼻。你還知雲門放洞山三頓棒底因緣麼？更是峭絕。所以慈明舉來勘驗黃龍，直得骨出，賊鎗賊弄，自然條直。今日不惜口業，索性引來一串穿卻。者箇洞山，是襄州洞山問佛答麻三斤底，不是新豐洞山。一日參雲門，門問：『那裏來？』答云：『查渡來。』門云：『夏在何處？』答云：『湖南報慈。』門又問：『幾時離彼？』答云：『八月十五。』門云：『放汝三頓棒。』洞山大疑。你看大賞之下必有勇夫，金剛寶劍劈面一揮，者箇手腳豈似你教人念死話頭、起疑情、裝模作樣底瞎宗師，如何啟發得人底真疑現前？者箇學人是生銕鑄就、有決定志底人，不是如今賣腳版、東走西走底人。聽見恁麼道，使一夜睡不去，心裏想道：『如此抵對，有甚錯誤？放我三頓棒，畢竟別有道理，與他理會去。』者箇豈不是真疑現前？天明便問：『昨晚蒙和尚放某甲三頓棒，過在什麼處？』果然不虛發藥。雲門道：『飯袋子！江西、湖南便恁麼去也。』你尋常說許多活潑潑、轉轆轆、解粘去縛處，還有者般手腳麼？此時洞山直下瓦解冰消。如今人要參禪，不具者般根性，如何參得禪來？所以道：參禪須是銕漢，著手心頭便判。便是者箇道理。如上所舉、如上所判，不是天童貶剝諸方、訶罵兄弟，只因明日開爐，見你一班輩後生英俊，發好心來天童參禪，所以直舉古人實證實悟、自見自肯處拈掇，貴圖正眼流通、宗風不替，不惜忉怛以至於此。然切不得記持一字，又不可隨著山僧舌頭轉，唯是把從前所學所得底，枝枝葉葉盡情向此無底爐中、不煙火內一併燒卻，與我斬新條，令別立生涯，忽地冷灰裏豆爆一聲，也不虛到者裏受勞受頓。久立，珍重。」
